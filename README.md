\# Staj Başvuru Onay Sistemi



Programlama Laboratuvarı III projesi. Öğrencilerin Ek-16 staj belgelerini yükleyip

otomatik olarak kontrol ettirebildiği ASP.NET Core MVC web uygulaması.



\## Grup Üyeleri

\- İrem Erkan (250229120)

\- Betül Akalın (250229060)

\-  Elif Nur Gelen (250229052)



\## Kullanılan Teknolojiler

C#, ASP.NET Core MVC (.NET 10), Entity Framework Core, SQLite, BCrypt.Net,

ClosedXML, Open XML SDK, PdfPig



\## Çalıştırma

1\. Projeyi Visual Studio ile açın.

2\. Paket Yöneticisi Konsolu'nda varsayılan projeyi StajEvrak.Infrastructure seçip

&#x20;  Update-Database komutunu çalıştırın.

3\. F5 ile uygulamayı başlatın.

4\. Admin hesabı: admin / Admin123!

5\. Admin panelinden test veri setini (veriseti.csv) yükleyin.

6\. Öğrenci olarak kayıt olurken veri setindeki bir öğrenci numarasını kullanın.
